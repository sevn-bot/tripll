# review-comment-triager

Classifies PR review threads into findings (design §11.12).

| Field | Value |
|-------|-------|
| **class** | triaging |
| **edits** | nothing (drafts only) |
| **done** | every open thread has a disposition |

PR loop pair: `review-comment-triager` → `review-comment-fixer`.
