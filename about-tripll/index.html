tripll

A headless, parallel wave-plan execution pipeline. Drop a set of plan files in, and tripll dispatches each wave to an agent backend in dependency order — with human gates, retries, and branch integration.

tripll turns a folder of wave-plan files into a deterministic execution graph and runs it end to end against a target git repository — no chat session required.

What it does

  1. Parse a plan set into a RunGraph — lanes, batches, Pre-0 gates, and content-window (CW) seams.
  2. Dispatch each wave to an agent backend (claude_code, cursor_local, cursor_cloud) in dependency order, each in its own git worktree.
  3. Stop at the Pre-0 human gate until you approve.
  4. Retry failed waves before escalating.
  5. Optionally integrate each batch onto a single branch.

Tech stack

Python 3.12+, src/ layout (hatchling + uv), loguru logging, optional Logfire/OpenTelemetry observability, and a FastAPI control plane with an HTML dashboard. MIT licensed.
