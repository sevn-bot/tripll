Dashboard

The optional FastAPI control plane gives a live view of runs, worktrees, and the Pre-0 human-in-the-loop wizard.

Run it

Install the api extra (bundled in make setup) and start the server:

make serve     # → http://localhost:8765

Set TRIPLL_API_TOKEN to require a bearer token; without it the server runs in open dev mode. Host and port are configurable via TRIPLL_SERVE_HOST / TRIPLL_SERVE_PORT.

What you get

  • Run list & detail — status, batches, and per-wave progress.
  • Live feed — orchestrator status tables and turn logs stream as waves run.
  • HITL wizard — resolve the Pre-0 gate from the browser: open a run, open HITL, complete the form, then submit & approve.
  • Worktree view — see each lane's worktree and branch state.

Human-in-the-loop

A run stops at the Pre-0 gate until decisions are recorded. You can resolve it three ways — the dashboard modal, the API, or the CLI interview (make pre0-interview RUN=<id>) — then approve and resume (make finish-pre0 RUN=<id> does all of it).

Log output is redacted using config/log-hide-keys.toml before it reaches the API or UI. Architecture and IA details live in docs/control-plane-design.md.
